# mineproj · AI 技能目录

本目录下的 `SKILL.md` 用于告诉 AI（以及协作者）如何理解并使用 mineproj 项目。
阅读顺序建议：先读 `mineproj-overview`，再按需查阅具体技能。

| 技能 | 用途 |
| --- | --- |
| [mineproj-overview](./mineproj-overview/SKILL.md) | 项目总览、仓库约定、AI 接手任务的第一入口 |
| [create-project](./create-project/SKILL.md) | 为一个使用者脚手架一个新站点 |
| [author-theme](./author-theme/SKILL.md) | 编写并发布一个主题 npm 包 |
| [author-plugin](./author-plugin/SKILL.md) | 编写插件（mineproj 钩子 + 透传 Vite 插件）|
| [content-authoring](./content-authoring/SKILL.md) | 用 JSON + Markdown 创作项目内容 |
| [visual-editor](./visual-editor/SKILL.md) | 使用与扩展可视化编辑器 |

> 这些技能描述的是本仓库的**既定架构与约定**（详见 `docs/plan/`）。实现期间以对应里程碑（M*）与最新代码为准；若技能描述与代码冲突，以代码为准并回头更新本目录。
