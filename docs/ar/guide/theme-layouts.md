# تخطيطات السمة والفتحات

## التخطيطات

يتطلب mineproj 7 تخطيطات أساسية. كل تخطيط هو مكون React يستقبل `LayoutProps`.

### تخطيط الصفحة الرئيسية

الصفحة الرئيسية. تعرض المشاريع المميزة، المشاريع الحديثة، ومعلومات الملف الشخصي.

### تخطيط القائمة

يعرض شبكة مشاريع مصفاة/مرتبة. يُستخدم في مسار `/projects/`.

### تخطيط التفاصيل

صفحة المشروع الفردية في `/projects/<slug>/`. تعرض تفاصيل المشروع الكاملة، محتوى النص، لقطات الشاشة، الفيديوهات، ملفات PDF، والعروض التوضيحية القابلة للتشغيل.

### تخطيط الوسم

يعرض المشاريع المصفاة حسب وسم في `/tags/<tag>/`.

### تخطيط المجموعة

يعرض المشاريع في مجموعة. يعمل بشكل مشابه لتخطيط الوسم.

### تخطيط حول

صفحة "حول" في `/about/`. تعرض معلومات الملف الشخصي.

### تخطيط غير موجود

صفحة 404. تظهر عندما لا يتطابق أي مسار.

## الفتحات

الفتحات هي نقاط تمديد حيث يمكن للإضافات حقن المكونات:

```ts
// في إضافة
export default definePlugin({
  name: 'my-plugin',
  hooks: {
    setup: (ctx) => {
      ctx.registerSlot('header', MyHeaderComponent);
    },
  },
});
```

الفتحات المضمنة تشمل عادةً: `header`، `footer`، `sidebar`، `editor-shell`.

## سلوك الرجوع الاحتياطي

إذا لم توفر السمة تخطيطًا، يعود mineproj إلى تخطيط السمة الافتراضية ويصدر تحذيرًا. هذا يضمن أن الموقع يُبنى دائمًا، حتى مع سمة غير مكتملة.

## سجل المكونات

يقوم سجل المكونات بحل المكونات بهذا الترتيب:
1. مكونات السمة
2. مكونات الإضافة
3. تجاوزات المستخدم (الفائز لاحقًا)

تجاوزات المكونات غير المعروفة تؤدي إلى تحذير.
