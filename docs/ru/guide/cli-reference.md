# Справочник CLI

CLI `mineproj` предоставляет все команды для сборки, разработки и управления вашим сайтом.

## Использование

```bash
mineproj <команда> [опции]
```

## Команды

### `dev`

Запуск сервера разработки.

```bash
mineproj dev [--port <n>] [--host <хост>] [--open] [--editor]
```

### `build`

Сборка статического сайта.

```bash
mineproj build [--outDir <дир>]
```

### `preview`

Предварительный просмотр собранного сайта.

```bash
mineproj preview [--port <n>] [--host <хост>]
```

### `check`

Проверка конфигурации и файлов данных.

```bash
mineproj check [--i18n]
```

### `new <slug>`

Создание каркаса нового проекта.

```bash
mineproj new my-project
```

### `audit`

Оценка собранного сайта по SEO, AI, a11y и производительности.

```bash
mineproj audit [--fail-under <n>]
```

### `doctor`

Диагностика окружения, конфигурации и состояния проекта.

```bash
mineproj doctor
```

### `info`

Показ разрешённой конфигурации, темы и диагностики плагинов.

```bash
mineproj info
```

### `theme:eject`

Копирование текущей темы в `.mineproj/theme/` для кастомизации.

```bash
mineproj theme:eject
```

### `i18n:init <locale>`

Создание каркаса новой локали.

```bash
mineproj i18n:init en
```

### `i18n:extract`

Извлечение непереведённых ключей по локалям.

```bash
mineproj i18n:extract
```

### `editor:export`

Экспорт черновиков редактора в виде JSON-патчей.

```bash
mineproj editor:export
```

### `migrate`

Миграция версии схемы и резервное копирование.

```bash
mineproj migrate
```

## Глобальные опции

| Опция | Описание |
|-------|----------|
| `--root <дир>` | Корневая директория сайта |
| `--config <путь>` | Явный путь к файлу конфигурации |
| `--outDir <дир>` | Переопределение выходной директории |
| `--port <n>` | Порт сервера разработки/предпросмотра |
| `--host <хост>` | Хост сервера разработки/предпросмотра |
| `--open` | Открыть браузер после запуска |
| `--editor` | Включить визуальный редактор (только dev) |
| `--fail-under <n>` | Минимальная оценка аудита (по умолчанию 85) |
| `-h, --help` | Показать справку |
| `-v, --version` | Показать версию |
