# শুরু করা

mineproj-এ স্বাগতম! এই নির্দেশিকা আপনাকে আপনার প্রথম প্রকল্প পোর্টফোলিও সাইট তৈরি করতে সাহায্য করবে।

## পূর্বশর্ত

- **Node.js** 22 বা তার পরের সংস্করণ
- **pnpm** 10 (`npm install -g pnpm` দিয়ে ইনস্টল করুন)

## একটি নতুন সাইট তৈরি করুন

সবচেয়ে দ্রুত উপায় হল স্ক্যাফোল্ডিং টুল ব্যবহার করা:

```bash
npx create-mineproj my-portfolio
cd my-portfolio
pnpm dev
```

আপনার ব্রাউজারে `http://localhost:5173` খুলুন আপনার সাইট দেখতে।

## প্রকল্পের কাঠামো

```
my-portfolio/
├─ mineproj.config.ts      # সাইট কনফিগারেশন
├─ data/
│  ├─ projects/             # প্রকল্পের ডেটা (JSON + Markdown)
│  │  └─ my-project/
│  │     ├─ index.json      # প্রকল্পের মেটাডেটা
│  │     └─ body.md         # প্রকল্পের মূল বিষয়বস্তু
│  ├─ profile.json          # আপনার প্রোফাইল
│  └─ tags.json             # ট্যাগ সংজ্ঞা
├─ public/                  # স্ট্যাটিক অ্যাসেট (ছবি, PDF, ইত্যাদি)
└─ dist/                    # বিল্ড আউটপুট (জেনারেটেড)
```

## একটি প্রকল্প যোগ করা

`data/projects/`-এর অধীনে একটি নতুন ডিরেক্টরি তৈরি করুন:

```bash
mineproj new my-project
```

এটি `data/projects/my-project/index.json` এবং `data/projects/my-project/body.md` তৈরি করে। প্রকল্পের মেটাডেটা সেট করতে JSON ফাইলটি এডিট করুন।

## প্রোডাকশনের জন্য বিল্ড করা

```bash
pnpm build
```

আউটপুট `dist/`-এ যায়। লোকালিতে প্রিভিউ করুন:

```bash
pnpm preview
```
