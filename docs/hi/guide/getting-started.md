# आरंभ करना

mineproj में आपका स्वागत है! यह मार्गदर्शिका आपको अपनी पहली परियोजना पोर्टफोलियो साइट बनाने में मदद करेगी।

## पूर्वापेक्षाएँ

- **Node.js** 22 या उसके बाद का संस्करण
- **pnpm** 10 (`npm install -g pnpm` के माध्यम से इंस्टॉल करें)

## एक नई साइट बनाएँ

आरंभ करने का सबसे तेज़ तरीका स्कैफोल्डिंग टूल का उपयोग करना है:

```bash
npx create-mineproj my-portfolio
cd my-portfolio
pnpm dev
```

अपनी साइट देखने के लिए अपने ब्राउज़र में `http://localhost:5173` खोलें।

## परियोजना संरचना

```
my-portfolio/
├─ mineproj.config.ts      # साइट कॉन्फ़िगरेशन
├─ data/
│  ├─ projects/             # परियोजना डेटा (JSON + Markdown)
│  │  └─ my-project/
│  │     ├─ index.json      # परियोजना मेटाडेटा
│  │     └─ body.md         # परियोजना मुख्य सामग्री
│  ├─ profile.json          # आपकी प्रोफ़ाइल
│  └─ tags.json             # टैग परिभाषाएँ
├─ public/                  # स्थैतिक संपत्तियाँ
└─ dist/                    # बिल्ड आउटपुट (जनरेटेड)
```

## एक परियोजना जोड़ना

`data/projects/` के अंतर्गत एक नई निर्देशिका बनाएँ:

```bash
mineproj new my-project
```

## प्रोडक्शन के लिए बिल्ड करना

```bash
pnpm build
```

आउटपुट `dist/` में जाता है। इसे स्थानीय रूप से प्रीव्यू करें:

```bash
pnpm preview
```
