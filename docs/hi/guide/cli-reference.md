# CLI संदर्भ

```bash
mineproj <command> [options]
```

## कमांड

| कमांड | विवरण |
|---|---|
| `dev` | डेवलपमेंट सर्वर प्रारंभ करें |
| `build` | स्थिर साइट बनाएँ |
| `preview` | बिल्ड की गई साइट का प्रीव्यू करें |
| `check` | कॉन्फ़िग और डेटा फ़ाइलों को मान्य करें |
| `audit` | SEO, AI, a11y, perf पर साइट को स्कोर करें |
| `new` | एक नया प्रोजेक्ट स्केलेटन बनाएँ |
| `doctor` | पर्यावरण का निदान करें |
| `info` | हल किया गया कॉन्फ़िग और प्लगइन दिखाएँ |
| `theme:eject` | थीम को स्थानीय निर्देशिका में कॉपी करें |
| `i18n:init` | एक नई लोकेल को स्कैफोल्ड करें |
| `i18n:extract` | अनअनुवादित कुंजियाँ निकालें |
